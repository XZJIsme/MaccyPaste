# MaccyPaste

语言：[English](README.md)

MaccyPaste 是一个轻量的 macOS 剪贴板管理器。它会保存你复制过的内容历史，并让你快速搜索、选择和再次使用之前的剪贴板内容。

MaccyPaste 是基于 [Maccy](https://github.com/p0deje/Maccy) 的个人 fork，不是官方 Maccy 版本。

MaccyPaste 支持 macOS Sonoma 14 或更高版本。

## 功能

* 轻量、快速
* 键盘优先
* 安全、注重隐私
* 原生界面
* 开源免费

## 安装

从 [releases](https://github.com/XZJIsme/MaccyPaste/releases/latest) 页面下载最新版构建。

MaccyPaste 目前还没有配置 Homebrew 安装。

## 使用

1. 按 <kbd>SHIFT (⇧)</kbd> + <kbd>COMMAND (⌘)</kbd> + <kbd>C</kbd> 弹出 MaccyPaste，或点击菜单栏图标。
2. 输入你要查找的内容。
3. 选择要复制的历史记录项：按 <kbd>ENTER</kbd>、点击该项，或使用 <kbd>COMMAND (⌘)</kbd> + `n` 快捷键。
4. 选择并粘贴历史记录项：按 <kbd>OPTION (⌥)</kbd> + <kbd>ENTER</kbd>、<kbd>OPTION (⌥)</kbd> + <kbd>CLICK</kbd>，或使用 <kbd>OPTION (⌥)</kbd> + `n` 快捷键。
5. 选择并以无格式方式粘贴：按 <kbd>OPTION (⌥)</kbd> + <kbd>SHIFT (⇧)</kbd> + <kbd>ENTER</kbd>、<kbd>OPTION (⌥)</kbd> + <kbd>SHIFT (⇧)</kbd> + <kbd>CLICK</kbd>，或使用 <kbd>OPTION (⌥)</kbd> + <kbd>SHIFT (⇧)</kbd> + `n` 快捷键。
6. 删除历史记录项：按 <kbd>OPTION (⌥)</kbd> + <kbd>DELETE (⌫)</kbd>。
7. 查看历史记录项完整文本：悬停等待几秒显示提示。
8. 置顶历史记录项：按 <kbd>OPTION (⌥)</kbd> + <kbd>P</kbd>。该项会移动到列表顶部，并获得一个随机但固定的快捷键。再次按 <kbd>OPTION (⌥)</kbd> + <kbd>P</kbd> 可取消置顶。
9. 清除所有未置顶项：在菜单中选择 _Clear_，或按 <kbd>OPTION (⌥)</kbd> + <kbd>COMMAND (⌘)</kbd> + <kbd>DELETE (⌫)</kbd>。清除包括置顶项在内的所有项目：按住 <kbd>OPTION (⌥)</kbd> 选择菜单中的 _Clear_，或按 <kbd>SHIFT (⇧)</kbd> + <kbd>OPTION (⌥)</kbd> + <kbd>COMMAND (⌘)</kbd> + <kbd>DELETE (⌫)</kbd>。
10. 暂停 MaccyPaste 并忽略新的复制内容：按住 <kbd>OPTION (⌥)</kbd> 点击菜单栏图标。
11. 只忽略下一次复制：按住 <kbd>OPTION (⌥)</kbd> + <kbd>SHIFT (⇧)</kbd> 点击菜单栏图标。
12. 自定义行为：打开 “Preferences...” 窗口，或按 <kbd>COMMAND (⌘)</kbd> + <kbd>,</kbd>。

## 高级

### 忽略复制内容

你可以让 MaccyPaste 忽略所有复制内容：

```sh
defaults write com.zenga.MaccyPaste ignoreEvents true # 默认是 false
```

这适合复制敏感数据的工作流。你可以先把 `ignoreEvents` 设置为 true，复制敏感数据后再设置回 false。

你也可以按住 <kbd>OPTION (⌥)</kbd> 点击菜单栏图标。只忽略下一次复制时，按住 <kbd>OPTION (⌥)</kbd> + <kbd>SHIFT (⇧)</kbd> 点击菜单栏图标。

### 忽略自定义复制类型

默认情况下，MaccyPaste 会忽略一些被视为机密或临时内容的复制类型。默认列表始终包含：

* `org.nspasteboard.TransientType`
* `org.nspasteboard.ConcealedType`
* `org.nspasteboard.AutoGeneratedType`

默认配置还包含以下类型，但可以移除或覆盖：

* `com.agilebits.onepassword`
* `com.typeit4me.clipping`
* `de.petermaurer.TransientPasteboardType`
* `Pasteboard generator type`
* `net.antelle.keeweb`

你可以在设置里添加更多自定义类型。要查看某个应用使用了哪些自定义复制类型，可以使用免费应用 [Pasteboard-Viewer](https://github.com/sindresorhus/Pasteboard-Viewer)。打开它，从目标应用复制内容，然后在左侧边栏查看自定义类型。原 Maccy 项目有一个[忽略 Adobe InDesign 复制内容的示例](https://github.com/p0deje/Maccy/issues/125)。

### 加快剪贴板检查间隔

默认情况下，MaccyPaste 每 500 ms 检查一次剪贴板，这对大多数用户已经足够。如果你想加快检查，可以用 `defaults` 修改：

```sh
defaults write com.zenga.MaccyPaste clipboardCheckInterval 0.1 # 100 ms
```

## 常见问题

### 为什么选择历史记录项时没有自动粘贴？

1. 确认 Preferences 里启用了 “Paste automatically”。
2. 确认 “MaccyPaste” 已添加到 System Settings -> Privacy & Security -> Accessibility。

### 设置打开 MaccyPaste 的快捷键时，提示该快捷键已被系统设置占用怎么办？

1. 打开 System Settings -> Keyboard -> Keyboard Shortcuts。
2. 找到该快捷键被哪里使用。例如 “Convert text to simplified Chinese” 位于 Services -> Text。
3. 禁用该快捷键或移除对应组合。
4. 重启 MaccyPaste。
5. 在 MaccyPaste 设置中重新分配快捷键。

### 如何恢复隐藏的底部栏？

1. 打开 MaccyPaste 窗口。
2. 按 <kbd>COMMAND (⌘)</kbd> + <kbd>,</kbd> 打开设置。
3. 在 Appearance 区域启用 footer。

如果不起作用，可以在 Terminal.app 中运行：

```sh
defaults write com.zenga.MaccyPaste showFooter 1
```

### 如何忽略来自 [Universal Clipboard](https://support.apple.com/en-us/102430) 的复制？

1. 打开 Preferences -> Ignore -> Pasteboard Types。
2. 添加 `com.apple.is-remote-clipboard`。

### 我的键盘快捷键在密码输入框里失效了，怎么修？

如果你的快捷键会产生字符，例如 `Option+C` -> “ç”，macOS 可能会在密码输入框中阻止它。可以用 [Karabiner-Elements](https://karabiner-elements.pqrs.org/) 把快捷键重映射为其他组合，例如 `Cmd+Shift+C`。查看[详细解决方案](docs/keyboard-shortcut-password-fields.zh-CN.md)。
